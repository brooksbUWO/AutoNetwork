# OLEDExample

Demonstrates OLED display integration with AutoNetwork status and QR codes.

## Features

- OLED status display
- QR codes for easy connection
- Display state machine
- Runtime information display

## Hardware

- ESP32 board
- SSD1306 OLED display (I2C, 128x64)

## Usage

Watch OLED display for connection status, IP addresses, and scan QR codes for quick access.
